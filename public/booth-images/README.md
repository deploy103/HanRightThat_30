# 부스 이미지

부스 소개(`summary`/`imagePath`)에 쓸 이미지를 이 디렉터리에 추가한다.

- 파일명은 영문/숫자/`-`/`_`만 사용하고 확장자는 `png`/`jpg`/`jpeg`/`webp`/`svg`만 허용한다.
- 관리자에서는 `/booth-images/파일명.ext` 형식의 경로만 입력할 수 있다 (외부 URL, `data:`, 경로 탈출 불가).
- 이 디렉터리는 Vite `public/` 규칙에 따라 빌드 시 `dist/`로 그대로 복사되고, 운영에서는 express가
  같은 포트에서 정적으로 서빙한다 — 별도 업로드 서버 없이 파일만 추가하면 바로 쓸 수 있다.
- 이미지 업로드 기능은 이번 범위에 없다. 배포 서버의 `public/booth-images/`에 직접 파일을 올린다.

`placeholder.svg`는 이미지가 없는 부스에 쓰는 기본 브랜드 그래픽이다. 삭제하지 않는다.
